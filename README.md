# Dossier de candidature — Kevin Dolié

Dossier de candidature interactif de Kevin Dolié pour le poste de **Manager Péri-Informatique, IA & Data — Crédit Agricole Toulouse 31**.

Page web autonome (HTML/CSS/JS, sans dépendance externe, sans étape de build), organisée en un accueil fixe et trois chapitres qui s'ouvrent en plein écran : Mon ADN, Vision et trajectoire du service, Conclusion.

## Contenu

- `index.html` — le dossier complet (page autonome, tout intégré : styles, script, contenu).
- `assets/` — photos de couverture des chapitres.

## Consultation

Ouvrir `index.html` dans un navigateur, ou consulter la version publiée :

**https://kevindle1.github.io/Cv_kevin_dolie/**

Une version imprimable (PDF) est accessible directement depuis le navigateur via la fonction Imprimer, grâce à une feuille de style dédiée intégrée au fichier.

### Publier une mise à jour

1. Pousser les modifications sur la branche `main`.
2. **Settings** → **Pages** → Source : branche `main`, dossier `/ (root)`.
3. Le site se met à jour automatiquement à l'adresse ci-dessus.
